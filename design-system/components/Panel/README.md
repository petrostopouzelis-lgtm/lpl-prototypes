Card surface with an in-card header band and content that runs flush to the edges — the wrapper for every table and list on the platform dashboards. Use `Card` instead when the content should be inset by 24px on all sides.

```jsx
<Panel title="Recent Assignments" action={<Button variant="primary">New Assignment</Button>}>
  <Table columns={[…]} rows={[…]} />
</Panel>
```
