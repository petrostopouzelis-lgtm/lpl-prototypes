Small highlight chip for article categories, facet labels and status callouts.

```jsx
<Tag color="secondary">Leadership</Tag>
<Tag color="yellow">Self-control</Tag>
<Tag color="green">Emotionality</Tag>
```

`color` maps to the facet palette (`yellow`, `green`, `magenta`, `purple`, `red`) plus `primary`/`secondary` for general use. Border is always the "full" shade of that color, background the "light" shade.
