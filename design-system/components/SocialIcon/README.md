Social link that cross-fades between its two SVG files on hover and scales to 1.2× with a drop shadow. The icon set is authored as `state=Default` / `state=hover` pairs — never recolor a single file with CSS filters.

```jsx
<SocialIcon label="LinkedIn"
  defaultSrc="/assets/icons/social/linkedin-default.svg"
  hoverSrc="/assets/icons/social/linkedin-hover.svg" />
```

Available pairs: Facebook, Instagram, LinkedIn, TikTok, X, YouTube, Website.
