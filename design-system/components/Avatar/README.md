Circular initials avatar on the primary gradient — used for candidates, coaches, the signed-in profile button and organisation badges. The platform has no photo avatars.

```jsx
<Avatar initials="EM" size="sm" />
<Avatar initials="LC" size="lg" gradient="var(--color-facet-purple-gradient)" />
```

In avatar stacks, siblings overlap by −10px with a 2px white border; the overflow counter uses a light-gray fill with gray text.
