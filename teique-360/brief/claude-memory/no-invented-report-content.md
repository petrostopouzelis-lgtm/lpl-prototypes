Do not write new copy (introductions, captions, explanations) or add new pages to an LPL report. Use only what the source report contains, and show a visible "Text needed" marker where wording is missing.

**Why:** On 2026-11-11 Petros objected when the TEIQue 360 build included an introduction and other wording I had drafted: "only include the old report contents for now nothing else". Report wording is LPL's psychometric content, not something to draft for them.

**How to apply:** In [[teique-360-report-project]] and similar report work, copy wording from the named source report word for word, keep anything extra switched off by default, and say plainly which parts are not from the source.
